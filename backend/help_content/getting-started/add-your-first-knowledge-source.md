# Add your first knowledge source

Knowledge sources give an agent trusted material for grounded answers.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open **Agents** and select the agent.
2. Open the **Knowledge** tab.
3. Select **Add source**.
4. Choose **File upload**, **Web page**, **Sitemap**, or **Write text**.
5. Supply the file, URL, sitemap URL, or text.
6. Select **Add source**.
7. Wait for the status to move from **processing** to **ready**.

File uploads currently accept PDF, DOCX, TXT, and Markdown up to 500 MB.

## What happens next

When the source is **ready**, its chunks are available to retrieval. Test a question that can be answered directly from that source.

## Troubleshooting

If a source becomes **failed**, open the relevant troubleshooting guide instead of repeatedly uploading the same file.
