# Workspace invitation SMTP preflight

**Scope:** Only the existing authenticated Workspace invitation creation and resend endpoints. This extends the current pipeline; it does not replace invitation routes, authentication, token rotation, encryption, mail dispatch, or the development synchronous fallback.

`issue_workspace_invitation` and `resend_workspace_invitation` load `EmailSettings` to calculate token expiry **before** `stage_invitation_email` can validate SMTP settings. An invalid SMTP configuration could therefore propagate a Pydantic `ValueError` as an HTTP 500 before the existing safe configuration handler was reached.

The additive `preflight_workspace_invitation_email` dependency is registered on the existing **protected** invitation router, after the existing authenticated-actor dependency. It checks only `POST /workspace/invitations` and `POST /workspace/invitations/{invitation_id}/resend`, and only for a principal carrying `members.manage`. It validates the existing cached `EmailSettings` *before* entering either service. A settings `ValueError` becomes a generic 503 without disclosing SMTP credentials or validation details. The endpoint retains authoritative permission enforcement, transaction rollback, and the subsequent encryption/dispatcher/SMTP checks. Member GET/PATCH/DELETE, invitation GET/DELETE, unrelated Workspaces and public accept/signup/preview/decline are unchanged.

The change is deliberately not a promise that SMTP is reachable or that queued email has been delivered. Regression tests: `backend/tests/test_workspace_invitation_delivery_preflight_unit.py`, existing `backend/tests/test_workspace_invitation_smtp_configuration_unit.py`, and the existing API/queue tests. Verify real HTTP 503 for both operations, no invitation/token/audit/job mutation on invalid config, appropriate 403 for insufficient permission, development fallback, live PostgreSQL/RLS and queue/SMTP integration before considering this feature accepted. The regression is committed, but complete repository tests and production topology are **not verified passing**.
